# Calculadora Python

Aplicación de consola con un menú de cuatro operaciones.

## Uso
1. Ejecuta `python src/main.py`.
2. Elige una opción del menú (1 a 5).
3. Introduce los dos números cuando se pidan.

## Estructura del código
- `calculadora.py`: clase `Calculadora` con las operaciones.
- `main.py`: menú interactivo.
